# Performance acceptance targets
Targets only, not measured. Dell OptiPlex 7490 i5/16 GB integrated Intel GPU, no external GPU, three existing outputs, 1080p maximum. Aim for local click-to-visible lyric p95 <=50 ms with a 1080p H.264 motion background; remote command-to-visible p95 <=100 ms on church Wi-Fi. Measure Main, Online and Stage individually (DisplayLink and M1 add separate latency). Record CPU/GPU engines, RAM, dropped frames, p50/p95/p99, input/output resolution/refresh and exact hardware. Compare original FreeShow with identical assets, transitions disabled. Use high-speed video for end-to-end measurement; internal timestamps are supplementary. Idle app RAM target <=300 MB excluding optional external engines. Test 40+ slide import in background without visible stalls; 24h soak; device disconnect/reconnect; network loss; crash recovery; offline operation; monitor and audio routing. No 4K/HDR requirements. Do not claim acceptance until measured.
